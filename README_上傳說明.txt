《鼠除大作戰》V2 圖片版 GitHub 上傳說明

1. 把 zip 解壓縮到 Windows 資料夾。
2. 進入 GitHub 的 mouse-adventure Repository。
3. 點 Add file → Upload files。
4. 從解壓縮後的 mole-adventure-v2 資料夾中，將 index.html 和 assets 整個資料夾一同拖到 GitHub 上傳框。
5. 往下按 Commit changes。若 index.html 已存在，選擇覆蓋它。
6. 確認 GitHub 的 Code 首頁看到 index.html 和 assets 資料夾。
7. GitHub Pages 重新部署後刷新原本遊戲網址即可。

這版使用過去企劃圖中擷取的角色與背景，並以程式平移、縮放、旋轉做角色動畫過渡。
原先的美術企劃圖並非合格的透明逐格原稿，因此此版是插畫整合測試，還不是逐格完整動畫版本；部分背景是原圖調色變體，需另製作才能做到六張真正不同的高解析場景。
